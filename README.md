# Idea-hub-platform
 Step 1: Install Node.js
 1. Go to https://nodejs.org/
2. Download "LTS" version (green button)
3. Install (Next > Next > Finish)
4. Open CMD/Terminal
5. Type: node --version    
6. Type: npm --version     
 Step 2: Install VS Code
1. Go to https://code.visualstudio.com/
2. Download & Install
3. Open VS Code
4. Install these Extensions (Ctrl+Shift+X):
   - ES7+ React/Redux snippets
   - Prettier - Code formatter
   - Auto Rename Tag
 Create Project (3 minutes)
Step 3: Create React App
 1. Open CMD/Terminal
2. Go to Desktop: cd Desktop
3. Create project:
   npx create-react-app idea-hub-platform
4. Enter project folder:
   cd idea-hub-platform
5. Open in VS Code:
   code .
